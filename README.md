The site shauligames.netlify.app is built around the classic Hangman word-guessing game and includes a basic user account system.
Users can be added, updated and deleted.
You can check whether a username already exists.
There is a login that checks the user’s password.
The password policy requires at least 8 characters, with at least one uppercase and one lowercase letter.
You can play Hangman.
You can view your Hangman score.
You can view a leaderboard comparing players.
Scoring rewards fewer wrong guesses with more points.
